# Underwater Robot Visualization

This repository contains a Unity visualization project for AUV, ROV, and USV vehicles.

- Unity version: `6000.5.2f1`
- Open project: `UnityProject/UnderwaterRobotScene_v1`
- Git LFS is required for the tracked FBX assets.
- Unity regenerates local directories such as `Library`, `Temp`, and `Logs`; they are not source-controlled project content.
- This repository starts from a sanitized, validated snapshot.
